- `domain/world-state.ts`：自然访问补货与持久设备/种植分层；原版工具/概率来源和已批准12秒作物合同。没有预解锁主线、锄地/喂养/战斗门槛。
- `domain/hopper-network.ts`：生产事务内实时邻接、方向、先推后拉、一件、8/7tick、全场景、有限源减/目标增及D05/D06取得；复用P6端口，而非把端口函数包装成网络。没有红石、箱子或掉落实体。
- `p7-world-1`迁移、world1访问/调度、crop1进度、manual重置确认边界，复用唯一活动时钟和原事务锁。原合成/炉输出门禁、24+11领取回归、21设置、9配方书生命周期不弱化。
