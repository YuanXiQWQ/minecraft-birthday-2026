# P7 世界、访问与时钟合同

2026-10-22。授权原文见[authorization.md](authorization.md)。用户对作物D08的明确答复是“接受完整推荐方案”；D04/D05(A)/D06/D07/工作站D08/D09不重开。

## 已批准的作物适配

小麦240个活动tick（12秒），在0/80/160/240 tick显示原版age0/2/5/7。手持实际选中的已解锁种子，短右键空预耕地种植；左键采收。未成熟只取得原版允许的种子事实，成熟取得小麦及种子事实；采后空地可重种。永久目录只记取得资格，不因播种减少；掉落的数量修饰器不变成另一套有限库存。

活动时钟仍是原processing-clock：只有可见游戏页面，背包、设备、设置中继续，全场景统一推进；隐藏/最小化、离线和仅生日主页不推进、不补算。多个游戏标签共用`:processing` Web Lock，没有第二计时器。渲染的50ms纹理动画请求不推进任何业务时间。

## 三层状态

- 作者配置：`domain/world-config.ts`。橡木、普通蛋与温带成年鸡牛是首版工程配置，不冒称用户指定的变种。保护资源/预耕地与建造区分离。
- 自然访问：`progress.world.visits[scene]`的epoch、removed和roll。初始无预授物；同一次访问采过的节点在刷新后仍消失。真实改变选中场景时，目标场景epoch递增并清removed；同源标签共享选中场景和访问状态，不各自生成独立资源数组。原版概率使用存档内可复现计数采样，种子不是每棵草必掉。
- 玩家持久层：`scenes[scene].stations/crops`。补货不清设备、内容或作物；没有写入成功就不消除来源。拆除按D07清实例及内容，不暗领输出；UUID不复用。作物growth1保存ticks，设备沿用工作台1/炉2/漏斗3。

只有登记的自然节点、作物和持桶牛交互可授予材料。树叶、背景泥土、水、建造区铺地、房屋和鸡的模型不是材料来源，也不开发战斗。错误工具仍破坏当前矿物，但不获得要求正确工具的掉落；离开再回来可恢复资源。

## 空间放置与调度

坐标是一方块一个逻辑单位，真实面命中点沿法线偏移后取整。检查当前作者体积、占用及上层放置时的下方设备支撑；删除支撑不自动摧毁上方设备，上方仍可交互/拆除，避免新增掉落物理系统。首版体积：

| 场景 | 最小坐标 | 最大坐标 |
| --- | --- | --- |
| 平原 | 2,0,-4 | 7,2,2 |
| 矿洞 | 1,0,-3 | 7,2,2 |
| 农场 | 1,0,0 | 5,2,2 |
| 家 | 3,0,-2 | 6,1,2 |

这些是作者首版待视觉审查参数，不是用户对尺寸的逐项最终批准。眼位均为0,1.62,7；现有Look的6px分流、±36°水平及±15°垂直界限继续使用，不引入新视线手势。窄屏只调整投影FOV，不抬高或平移眼位。

短右键打开设备或向空位置放置；Alt+短右键向现有设备的实际命中面贴放持有设备，避免抢占正常Use；Shift+短右键拆除。R旋转悬停设备，否则调整预览朝向。GUI门禁先取消世界手势；右拖只转向、不同时Use。输入映射仍需实体鼠标/跨环境检查，不能把规则测试当人工验收。

每个权威tick先推进所有场景的炉/作物，再按plains/cave/farm/home和持久实例顺序调度漏斗。漏斗先推后拉，各方向最多一件；成功工作冷却8tick，空目标漏斗按原版已/未在本tick处理的关系协调8/7tick。不是Minecraft完整区块调度模拟。

原实例旋转保留剩余冷却，不能靠连按R加速；拆除才删除该实例调度身份，重放使用新UUID。

网络在事务内读取最新坐标、朝向和内容，动态寻找相邻端点，不缓存UI提供的连接。普通生产端口计划也需同场景、真实邻接和一件上限；原P6独立端口测试策略保留为测试边界。输出转移成功才在同一保存事务中源减、目标增、永久取得及D06发现；空源、满目标或非法端口不取得。输入/燃料持续加工引用和有限物流移动分开，不复制来源。
