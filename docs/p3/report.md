主页标题/故事/邀请是 `app/web/src/i18n/en.json` 的可编辑英文初稿，不是最终文案，也不是把用户中文示例硬编码。收件人/赠送人来自 birthday.json。只有点击邀请才导航游戏。主页有真实实时 WebGL2 几何/透视/遮挡，桌面由原版橡木台阶与栅栏柱模型组成的作者 prefab 构成，明确采用表现用缩放，不声称存在原版“桌子方块”。蛋糕使用原版未切模型，只有唯一放置事实成立才出现。

游戏是独立第一人称承载页，沿用近眼高/中央构图/无准星/自由鼠标摄像机射线；屏幕设置隔离场景输入。没有把 P2 测试场地冒充最终农场，没有自由移动/Pointer Lock/新视线手势。正式放置合法区域、完整工作站/GUI与四场景留给对应阶段；状态接口保留 B 所需实例/坐标/朝向。

## 状态、持久化与本地化

完整字段、版本、命令、并发与错误路径见[存档契约](storage-contract.md)。永久解锁幂等/单调，主线固定排列与副产物首次顺序分开；hydrate不重播首次通知。完成事实只有 cakePlacement；庆典播放状态暂存内存且加载不播放。自然资源运行态与玩家持久层分离。

锁内执行“读取最新值→校验→命令→校验/封装→一次写入”，加 generation、确认 token 与页面 serial，解决协作多标签排队和重置旧写；不是仅用 revision。无锁只读，不降级为不安全写入。损坏/未来/未知/写失败有英文反馈，不覆盖或删除原档。仅有 development-v0 合成迁移示例，不声称迁移旧实验数据或已经实现备份恢复产品。

用户已批准 **重置进度、保留语言和音量**；设置还保留静音。重置只触及本项目key，主页立即恢复空桌；不增加“完成生日”玩家按钮。完成投影通过独立测试源的明确命令夹具验证，正常dev/build不含夹具入口。

本地化解析器支持未来语言逐键回退英文、参数校验；缺英文键测试失败。HTML标题、noscript、错误、故事、按钮与可访问标签均外置。当前只有英语，字体只支持已验证 ASCII；新增其他语言还需相应原版字形提供者，不宣称已经全Unicode。
