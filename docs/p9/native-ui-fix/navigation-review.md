# 文字颜色与顶部悬浮导航

基线3927f3917ddecf47f089abe9179111a357aaa293，main与origin/main一致且起始工作区干净。仅修改显示层，不改五项修复、数量、存档、聊天分类、指针或生日合同。

## 实现

- PixelUI.text默认颜色从暖色#FFF7DE改为中性#FFFFFF；CSS默认文字、标题及焦点边框使用中性白色。保留显式语义颜色，例如失败红色、稀有度、配方书标题金色。
- 游戏入口不挂载header，不创建Welcome品牌文字；主页生日文案与设置入口保留。
- 四个原版精灵按钮使用顶部居中的局部悬浮导航，梯形底座不占文档流，3D视口从y=0开始铺满。菜单/容器仍属于游戏视口，外部场景导航可用。
- 深色取自[MC官网组件样式](https://www.minecraft.net/webui/mc-components.min.css)的mc-core-off-black #171615、mc-core-grey-6 #262423及grey-5 #3d3938；依据用户自主执行授权选择渐变、梯形形状与间距，不声称官网本身使用这个导航布局。
- 文字画布按实际按钮中心定位，使用原版字体8逻辑像素的显示高度；保留整数GUI字形绘制、选中/悬浮精灵及语义按钮。390像素视口保持四按钮单行。

## 回归

正式441项测试通过（保留原440项，新增全高放大菜单标题间距回归）。已有文字重绘去重测试的默认缓存颜色更新为白色并新增白色断言；仍校验100次相同文字不重绘及修改文字/比例/显式颜色触发重绘，不删除原安全测试。类型检查通过。

新增显示适配：全高视口1440×900在共享GUI scale≈4时，有限三按钮菜单原布局与title重叠；按钮组现在至少位于titleY+14逻辑像素，实际标题bottom196、首按钮top216，保留原生锚点与精灵，不改菜单业务。

截图工具边界：CSS视口1440×900、390×844分别实际返回1331×900、390×843的图像，文件名明确记录实际栅格；这些图像只证明可见内容，不计作精确尺寸完整截图通过。invalid-resize/invalid-selected-tab文件保留为过渡帧或错误标签尺寸的无效证据。1280×720 PNG实际尺寸完全匹配，颜色/居中测量只基于该帧。
