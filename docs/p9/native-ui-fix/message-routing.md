# 消息去向与事件边界

|原消息源|实际触发|新位置|去重/生命周期|
|---|---|---|---|
|隐藏story/game.worldHint|首次同步有效存档代次|聊天系统消息|同代次一次；新代次重新教学|
|首次取得教学|首次真实item-unlocked|聊天，独立于物品名字彩色段|每代次首次一次；hydrate不重播|
|items-acquired|正式事务的有效掉落/实际入包/未入包字段|正常入包静默；仅容量余量进入聊天|不因snapshot/render重新发送；来源一次结算合同不变|
|item-unlocked|实际首次领取/采集提交|聊天：原名称与Epic蛋糕颜色|永久事实幂等；不由预览触发|
|隐藏caption/scene|真实scene标识转换|聊天场景名|连续同场景不重复；非每加工tick|
|挖掉方块/设备|已提交破坏及实际有限入包|原版破坏效果/声音，无成功聊天|首次解锁/容量不足/失败独立处理|
|WorldUse结果|已提交放置/旋转/种植/蛋糕Use、实际失败|聊天系统反馈|一次操作事件；不把无掉落说成取得|
|隐藏selection|表选择/图形上下文lost/restored|聊天状态反馈|相同状态连发去重；lost/restored交替均可见|
|saveStatus|ready/migrated/读取失败/写入失败/恢复的状态转换|聊天；严重错误仍显示状态及Retry|不按revision发送；错误→恢复可再发|
|资源/WebGL初始化失败|实际异常|聊天就绪则聊天，否则可见caption兜底|不丢初始化前重要反馈；无假2D世界|
|原生通知/容器反馈|发现、材料冲突、容量不足、设置保存与失败|配方Toast/容器内提示/设置状态|保留就近操作反馈；不误迁物品Tooltip、标题或按钮|
|正式生日祝福|已保存cakePlacement后的演出|既有生日界面|未改触发/重播/清理，不作为聊天伪作者发言|

`feedbackStates`只去重明确状态边界，不去重每次合法玩家操作；初始化前有限消息队列在聊天创建时按序交付，重要错误同时有可见兜底。文本均经外部英语回退资源，聊天安全绘制为文本和受控颜色段，没有HTML执行或联网发送。
