# 物品搜索焦点、指南针及现有通知核对

基线71b61ac；用户后续明确“搜索物品页打开后自动聚焦，直接输入，不是配方书搜索框始终显示光标”。本项不更改数量、存档、配方、庆典或既有输入票据合同。

## 同版本依据与实现

- Java26.3 `CreativeModeInventoryScreen.selectTab` 的SEARCH分支依次调用`setVisible(true)`、`setCanLoseFocus(false)`、`setFocused(true)`；其他页恢复可失焦并取消搜索焦点。`keyPressed`先处理适用的悬浮槽数字快捷键，再交EditBox捕获文本。之前只移植了输入框画法，漏掉了所属页面的自动焦点合同。
- `GameInventory.open`和点击物品搜索书签时调用正式`focusCatalogue`；在该页点击槽位/页内背景不抢走搜索焦点。字母直接进入搜索，Esc仍关闭；适用悬浮槽的数字操作先路由到已有复制/交换且仍由既有权限校验。不向世界透传。
- `nativeField`没有新增“假聚焦”或“永久亮光标”开关，仍按焦点和原版300ms规则闪烁。配方书搜索没有自动聚焦；其提示、聚焦及光标保持原有独立配置。
- `CreativeModeTabs`的搜索图标提供普通COMPASS，`extractTabButton`交`GuiGraphicsExtractor.item`；后者传入实际玩家/世界，`CompassAngleState`按出生点/所有者朝向计算，目标无效才走旋转分支。**原版在所有世界、所有观察方向中并不存在唯一强制固定帧。** 此事实不能被改写成“原版代码始终锁某个帧”。
- 本项目按用户要求固定书签方向，并与用户原版对照图的朝左上红针对齐：使用原版`compass_12`模型、父继承与原始纹理，不旋转/重绘图片，不模拟出生点导航或随时间转动。这是依据用户自主执行授权作出的固定UI符号选择。提取脚本明确选择该原版叶子，不再把range列表第一项当作原版菜单规则。配方书共用的指南针符号也一致固定，内容物品数量和取得资格不受影响。

只读字节码/资源哈希见[catalogue-native-evidence.json](catalogue-native-evidence.json)。没有启动客户端或操作实体桌面。资源按现有清单进入Git及普通构建；固定帧替换不增加运行资源文件总数（675，含九份清单），导出器哈希已更新。

## 当前仍保留的自动通知（完整说明）

|位置|目前仍实际发送的内容|频率/边界|
|---|---|---|
|聊天|首次永久取得；首次取得后的无限图鉴教学|事实首次提交；重复取得不重发首次通知|
|聊天|进入游戏页面/新代次的操作说明|每次页面运行生命周期/新代次一次|
|聊天|场景名称|初次投影或切换场景，不按每tick发送|
|聊天|保存就绪、旧档可迁移、保存失败及恢复|状态转换，不是每次保存写入都提示|
|聊天|设备放置、设备旋转、播种成功|目前每次成功操作仍发；之前回复漏报了这些普通成功消息，本次按用户要求如实列出，未擅自删除其他类型|
|聊天|蛋糕放桌及未持蛋糕时的桌面说明|实际桌面Use结果；不由合成触发|
|聊天|容量余量、容器容量不足、位置非法、操作失败|实际事件/失败；不把余量写成已入包|
|聊天|图形上下文丢失/恢复、初始化失败、指针锁失败、音频被阻止/样本失败|实际失败或状态边界；严重保存/初始化错误仍保留可见恢复入口|
|原版Toast/控件|首次新配方发现Toast及ui.toast.in/out，配方控件提示动画|实际首次发现、原版瞬时时间线；hydrate不重播|
|GUI内就近文字|材料返还、合成/领取/填料冲突、满包返还失败、设置保存/重置失败|对应界面内提示，不伪装成玩家聊天|

普通入包的`+数量`和方块/设备挖除成功文字已在71b61ac删除，本次保留；破坏粒子/声音不是文字通知。玩家主动发送的本地聊天、Tooltip和实际生日演出也保持，不新增伪作者消息。

## 实际验证

- 正式测试422项（保留原418项，新增4项）。新增使用正式GameInventory.open/focusCatalogue与InventoryInput.key，覆盖立即聚焦、重复请求、个人页/设备/配方书不串焦点、文本快捷键、悬浮数字路由和Esc；指南针核对原模型引用及来自客户端的独立纹理SHA-256。
- 隔离普通`/game/`、1280×720、DPR1.25、GUI倍率2.4（正式DOM记录），无授物/改档：按E打开后AX焦点立即为Search Items，未点击输入框直接用原生键盘o/a/k得到`oak`。点击空槽后输入f得到`oakf`，焦点仍在搜索；切个人页并打开配方书，焦点为Toggle recipe book而不是Search recipes；返回物品搜索和Esc关闭重开后都自动聚焦。
- 实际画面和状态见[catalogue-evidence/](catalogue-evidence/)：`open-search.jpg`包含未点击即出现的下划线光标与固定指南针；`direct-typing.jpg/json`为原生键盘输入；`retained-focus.json`、`recipe-book-focus.json`、`reopened-focus.json`分别记录上述焦点边界。没有把DOM合成输入称为原生操作。
- 类型检查、P4核验、根路径/Pages构建及HTTP/资源检查执行，最终CI/部署及线上构建ID分别于交付回复核实。实体输入/人工听觉/Java动态并排等既有未验项不因本项变为通过。
