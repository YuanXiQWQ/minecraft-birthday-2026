# 新增物品优先使用快捷栏

基线`f985f47`。用户要求快捷栏有空位时优先接收新增物品；保留并行矿洞改动，不将其混入本次定向提交。

## 修正

原自动采集用`playerTargets`的主背包27格→快捷栏9格顺序。没有兼容组时，新原木直接占主背包0，即使快捷栏全空。

新增`storeAcquired`统一自动取得路由：先合并已有兼容组（快捷栏同类组优先），需要新增组时，先选快捷栏空格，随后主背包空格。原版数量/组件比较与容量仍由正式`quickMove`负责。保留全局同类合并，避免小麦本可并入现有组却占掉最后空格、使种子无谓溢出的容量退化。

覆盖普通采集、作物采收、正确工具拆设备的实际掉落、额外奶桶入包、合成余留物溢出输入格时的返还，以及合成/炉输出Shift自动领取。普通采集按快捷栏0→8；Shift保留菜单原有8→0顺序。明确指定数字格、副手、光标、手工取放及正常关工作台返还保持原规则。没有扩大自动收集来源、增加隐藏库存或提前解锁。

|同一用例|修正前|修正后|
|---|---|---|
|27+9全空，采一根原木|主背包0=1原木，快捷栏全空|快捷栏0=1原木，主背包全空|
|快捷栏已有63原木，还有空格|新组按主背包顺序填|先补已有组，再使用快捷栏空格|
|快捷栏满，主背包有位置|主背包接收|继续主背包接收|
|背包已有兼容余量|先合并|继续先合并，组件不兼容不混合|
|两区全满|有效取得/溢出反馈规则|完全保留；不复制、不吞其他材料|
