# 聊天节奏与鼠标快捷键

用户要求作者消息延迟与分条发送，系统教程仍立即显示；新增第八条场景导航说明，中英文均使用本地化资源。仅游戏首帧与 HUD 就绪后启动序列，发送目标为第 3、8、13、18、23、28、33、38 秒，固定作者 YuanXiQWQ。进入文档时只启动一次，切场景、存档更新、设置开关不会重播。离开文档取消未发送消息，BFCache 自然冻结/恢复同一队列。依据自主执行授权采用串行 timeout：若浏览器后台节流或冻结，恢复后不会补发多条积压消息；下一条仍等待 5 秒。待发文案按发送时当前语言解析，已发历史保留。

系统控件教程去掉右键拖动，在末尾加入 Ctrl + 右键提示。世界输入门禁放行时，该组合键优先于挖掘、Use 和可见指针拖动，按下即取消已有手势并切换鼠标状态，松开不触发 Use。物品栏、聊天、暂停、设置与进度 UI 关闭世界输入，不拦截它们各自的 Ctrl 操作。正常初次左键点击可以获取锁定；普通右键只走原来的使用/放置行为。手动释放后需再次 Ctrl + 右键进入隐藏观察，不因普通点击重锁。可见指针拖动观察仍作为原有回退能力保留。

定位到的误触路径是“短按右键且目标不可使用时切换锁定”，本次移除。窗口失焦、document.hidden 和 pagehide 会释放实际锁定、废弃待处理申请并保持可见；迟到成功回执不能恢复锁定。内部场景初始化只取消当前所有权，不把尚未开始的首次点击入口禁用。
