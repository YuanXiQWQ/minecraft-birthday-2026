# 本地挖掘声音居中

基于`4c3cf276307005c3108dd201b81f0b67434a2ad6`，按用户最新明确要求：玩家固定不能靠近方块，因此自己挖掘的命中声和破坏完成声在客户端居中播放，不按方块距离衰减。此要求覆盖上一实现中的方块坐标声源；原版材质、样本、4tick节拍、音量/音高及生命周期保护保留。

## 修正范围

上一实现的命中声在方块中心创建WebAudio Panner，线性16格衰减；普通自然方块的完成声没有空间节点，设备完成声有空间节点。正式固定眼位到部分远端原木接近16格，这会明显削弱命中声；此前`scheduled`及gain记录位于Panner之前，没有证明用户实际可听。

`WorldUse.miningSound()`不再传入世界坐标；设备破坏成功的声音也取消世界坐标。`WorldAudio`沿用已有无position直连输出路径，左右居中，不随相机/目标距离变化。主音量、方块音量、静音、原版音高和材质事件保持；没有全局删除Panner，雨/雷等原有带位置环境声音不改。诊断记录增加实际`spatial`标记，避免再以衰减前gain代替输出接线证据。
