# 降水方向定向修正

2026-10-23。实际基线为后续main `5beabff`，保留该提交的草原升级，以及加载画面、音频/计时和所有物品/存档功能。开始时工作区干净，分支main与origin/main一致。

## 复现与根因

`NativePrecipitation.rebuild()`将每个顶点的V写为`y*.25`。shader使用原版负向时间偏移，两者叠加使同一雨纹向世界Y正方向移动。只检查偏移为负或雨图非空不能发现这个问题。

只读核对同版本`WeatherEffectRenderer.prepareInstances()`确认：原版**topY顶点使用bottomY×.25+vOffset，bottomY顶点使用topY×.25+vOffset**。本实现没有保留这个上下对调，因而雨纹向上。另将原生上起点的纹理坐标交给CanvasTexture默认flipY=true，造成了多余的纹理翻转。[class哈希/方法依据](native-evidence.json)。未启动Java客户端。

修正统一映射为`(top+bottom-y)*.25`，纹理明确`flipY=false`。雨与雪共用该几何，两种纹理一起校正。原版雨速、雪的随机飘移、部分tick连续动画、雨强、屋顶高度截断、实例缓存、天气/活动时钟和声音调度未修改。

## 同条件实际GPU证据

隔离`rain-motion.html`直接实例化正式`NativePrecipitation`，加载正式校验资源，取真实第一根柱的几何和同一生产shader，在正交相机中渲染四帧；无另外一套雨shader。只将背景置黑以明确观察原像素，不放大亮度或编辑图像。帧是GPU输出复制到2D画布后的原始PNG，top-origin像素位移通过前后帧特征相关性独立计算，不从UV符号推导预期。128×256物理像素，固定同柱、seed及原版纹理。
