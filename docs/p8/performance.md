# P8与有限运输性能实测

环境：Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/155.0.0.0 Safari/537.36；1440×900、DPR=1.0000000149011612，当前IAB WebGL renderer/vendor=WebKit WebGL/WebKit。GPU timer query实际可用，未取得低端设备/其他引擎证据。测试未并行构建、单测或HMR源码改动；固定2632026种子，20秒编排，原版模型/GUI/声音、Trail/Twinkle保留。普通页面真实SaveSession/共享时钟，隔离只读观察器不授物、不改存档。阶段span为墙钟耗时，可能包括异步等待，不能直接相加当CPU时间。

每次5秒预热，再连续观察60秒。演出观察窗包含前两次演出与中间空档；另有三个完整20秒run摘要，**不冒称整个60秒观察窗都是三次无缝演出**。链是玩家普通操作搭建、普通目录取有限64原木后GUI放入；无预置网络。链采样中有一次GUI查看/截图，保留该条件。原始JSON包含所有timings/frames/longtask可供独立分析。

复现：`npm run dev -- --mode verification --port 4195`，在已有真实进度的`/game/?measure=1`点Measure，预热5秒/观察60秒；按正常页面Replay或在普通GUI补料运行链。`tests/ordinary-observer.ts`无授物/存档操作，普通dev/build均不加载。1920截图单独使用已有P3隔离夹具准备完成事实，只验证排版，不充作新档主线/性能证据。

采样与最终源码区分：60秒文件早于最后的静止光标缩放、碎屑RAF/水道支撑、来源区域Shift及配置参数边界回归；本样本的默认20秒粒子/声音时点、炉tick与运输算法不变。最后源码另有20秒冒烟（明确由隔离完成事实准备，非新档主线）：2742帧、p95 14.6ms、max46.6ms、>16.7/33.3/50为82/4/0，35调度、11913粒子峰值、释放1/1。冒烟期间有截图，不能将其当60秒协议比较。未用这些数据宣布P9或全设备性能通过。
