**真实客户端验证前**：明确独立26.3客户端环境/合法安装位置、可运行范围和记录方式，不读取账户凭据、不自动接受EULA或安装工具。现有Java25可做静态读取，不代表客户端环境已准备好。若需要额外反编译器、数据生成器、图标渲染器或浏览器包，先列实际工具及原因；本轮均未安装。

**工程P2前**：仍需明确授权建立Vite/React工程、安装项目依赖和执行限定的GUI/烟花/音频原型。不得把本次P1授权或总体初审当作P2开工批准。目标设备/浏览器、触控深度至少应确定首轮验证基准，具体音乐和最终文案可留P8定稿。
