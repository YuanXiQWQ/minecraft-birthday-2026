# P2人工验收清单

全部项目初始状态均为 **待人工验证**。脚本、音频波形、截图和自动化事件记录不会勾选本清单；只有用户真实操作、试听并反馈后才更新结果。记录日期、浏览器/版本、操作系统、屏幕/DPR、输出设备与系统/页面音量。出现问题保留步骤、开发诊断和截图，避免只写“感觉不对”。

## 准备

在 `experiments/scene3d/` 安装锁定依赖后运行 `npm run dev`，或 `npm run build` 后 `npm run preview`。打开 `/game/`，模型/GUI/粒子/声音应默认已加载，不需要私有缓存或加载按钮。测试按钮仍在 Developer tools，不是正式生日结局入口。默认场景环境仍有明确的示意几何，不代表完整四场景已制作。

## 真实后台、最小化、恢复

使用正常桌面浏览器：开始组合烟花后分别切换其他标签、最小化窗口，各等待至少10秒后返回。保存diagnostics中的visibility记录、paused与AudioContext状态。

- [ ] 待人工验证：确实出现可信 hidden 事件，模拟和音频暂停；后台期间没有声音继续播放或GPU忙循环异常。
- [ ] 待人工验证：返回后按明确Resume，沿原时间继续，不集中补放后台期间的爆炸/尾音；再Cancel确认清理。
- [ ] 待人工验证：同样操作时打开二维GUI，GUI与场景输入仍隔离，关闭后无失效设备ID。
- [ ] 待人工验证：系统挂起/输出设备切换等浏览器中断若发生，记录实际上下文状态和恢复动作；未经测试不推断通用支持。

- [ ] 待人工验证：右键拆半后按住右键拖过三个空槽、回到已过槽再松开；记录事件顺序与数量，不把合成回放当实体右拖。
- [ ] 待人工验证：左右拖动中途按Esc，再开GUI；没有幽灵拖动、重复放置或场景误点击。
- [ ] 待人工验证：拖动中切出窗口/失焦，再返回并松开；未完成手势取消，场景没有误放置。
- [ ] 待人工验证：文本焦点内E/数字键正常输入，Esc行为可理解；关闭GUI后原版屏幕层不再拦截场景鼠标。
