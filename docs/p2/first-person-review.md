# P2 第一轮修正：第一人称场景、布局与输入

日期：2026-10-20（America/Vancouver）。修正基线为 `5da7c4e7fff3471730b86beee2fb8e520a1a6b27`。本次仅完成用户授权的首轮视角、页面布局、必要输入适配与回归，不宣布完整 P2 通过。原始 P1、原始会话、首次 P2 证据和实际性能记录保留原样。

## 1. 当前决定和交付

四个正式场景必须从场景内部、接近眼高的第一人称观察；三维场景是网页主要视觉内容，主要对象居中构图，无准星或瞄准标记。继续用自由鼠标指针经真实摄像机射线拾取对象及方块面，不强制中心瞄准或 Pointer Lock。没有玩家移动、WASD、飞行、随机世界、战斗或红石网络。

独立原型仍位于 [experiments/scene3d](../../experiments/scene3d/README.md)：

- `camera.ts` 将观察配置与逻辑布局分离。默认眼位 `(0.5, 1.62, 6.5)`，看向 `(0.5, 1.35, 0.5)`，透视 FOV 为 70°；Left/Right 也保持 y=1.62。窗口尺寸只改变投影比例，不再把眼位抬高或拉远。这些数值仅为技术夹具，未声称是 Java 26.3 的精确相机参数。
- `scene-adapter.ts` 使用真正 WebGL2 网格、深度与射线；增加有限作者摆放的调试树木/石块和地面，让眼位处于环境内部。没有生产四个场景，没有环境采集或世界模拟。
- `main.ts` / `style.css` 让场景填满 `100dvh` 主视区，标题和状态采用紧凑屏幕覆盖。Inspect、Place、Remove、设备/方向、观察预设、存档、性能和 JSON 收入默认隐藏的 Developer tools。网格与邻接诊断线随面板显示；展开面板不缩小画布或改变世界坐标。
- 仍从实际鼠标位置换算射线，取最近可见表面。放置预览保留真实模型变换和深度测试，自身不参与拾取。稳定 ID、坐标、朝向和邻接规则不变；存档仍使用独立 `layout-v1` 键及 schema 1。
- 屏幕二维设备窗口打开时，遮罩拦截指针，背景 header/开发面板 inert；场景动作另有模态门禁。动作要求同一指针先在画布按下，窗口打开/关闭、模式切换、离开、取消或失焦取消未完成动作，避免释放事件越过 GUI 后触发场景。
- `labels.ts` 提供实验英文文案；所有新模型均为自行编写的平色调试几何，并在页面明确标为 DEBUG GEOMETRY ONLY。没有加入任何原版模型、贴图、字体或声音。

## 4. 初步桌面性能

协议沿用首轮：每档三次，每次2秒预热+10秒采样，真实 requestAnimationFrame 间隔；1440×900 CSS画布、1800×1125 backing pixels、Front眼位，开发面板在主要采样期间收起。面板切换本身可能包含在预热/短时采样中，不据此宣称严格隔离的GPU基准。全部原始帧序列见[performance-1440.json](evidence/first-person/performance-1440.json)。

| 负载              | 实例 | draw calls / triangles | 三次平均帧率              | p95帧间隔     | 最大间隔           | >33ms |
|-------------------|------|------------------------|---------------------------|---------------|--------------------|-------|
| 原始夹具+调试环境 | 7    | 55 / 644               | 240.0 / 240.0 / 240.0 FPS | 三次均约4.3ms | 4.6 / 4.5 / 4.7ms  | 0     |
| 密集夹具+调试环境 | 38   | 196 / 2272             | 240.0 / 239.8 / 239.9 FPS | 三次均约4.3ms | 4.7 / 12.6 / 8.3ms | 0     |

这些是浏览器RAF调度与提交帧的短时观测，不是纯GPU执行时间、显示器呈现帧率或完整场景验收。没有真实原版纹理、GUI纹理、粒子/烟花/音频，没有完整四场景负载或正式性能预算；内置浏览器与独立桌面浏览器的前后台调度差异、低端GPU/触控、长期资源趋势、意外上下文丢失恢复仍未覆盖。首次310×610窄画布数据仍保留原文件，不能将本次桌面数据回写进去。

构建仍有游戏chunk大于500KB的提示；未提高告警阈值。根/子路径游戏JS为557761字节，审计gzip为140390字节；主页JS闭包3759字节，不加载Three.js场景。没有新增资产分发许可结论。
