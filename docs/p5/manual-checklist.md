# P5 尚待实体输入与跨环境验收

以下均为**待人工验证**，没有收到用户反馈前不得勾选通过。普通4183新档未解锁时不可测试全部组；请用`app`的dev:verify，在4184/__verify__/index.html解锁测试目录，再访问同源/__verify__/input.html。真实Java26.3客户端对照需另行安排，本任务没有启动客户端。

1. 世界无GUI：右键短击桌面仅Use；按住右键拖过阈值，视角有限转向且不Use、不移动；松开后再短击正常。无Pointer Lock、准星、WASD。
2. GUI内光标持木板10，按住右键依次拖过九格1/2/2/3及非法胸甲槽，每个合法格各1，重复格不重复；视角完全不变。再用中键拖动把三个合法格填64；奶桶填1，桶填16。不要把中键单击当中键拖动。
3. 左/右/中拖动中按Esc、Alt-Tab/点击别窗、最小化、移出浏览器；未提交分配取消。返回后没有幽灵拖动、意外世界Use或第二套有限库存。Esc的光标退出数量政策仍待D07，不以当前临时内存行为批准它。
4. Shift单击/Shift双击装备与真实临时槽；目录只作有界复制。确认当前无容器时普通九格Shift不创建有限背包，不扫描无限来源；P6才新增站点目标。
5. 不同组件相同ID、装备已占用的合法交换、数字/F、Q/Ctrl+Q、C/X组合及浏览器右键菜单。Firefox/其他OS的Ctrl+Q可能被浏览器保留，应记录实际事件和是否能阻止；不要把Chromium结果外推。
6. 窗口尺寸/DPR/浏览器缩放改变时保持字体、数量、Tooltip与槽位命中对应。当前已记录700×600 GUI2×、1280×720和1440×900 GUI3×、DPR约1/1.25；其他组合待验。
7. Chrome/Edge/Firefox、隐私模式、禁用Web Locks/存储或磁盘额度不足；已有原档不能无提示覆写。实际BFCache命中与长时间后台恢复仍需对应环境。
8. Java26.3对照：创造源增减、组件默认等价、Shift双击来源范围、中拖、占用装备交换和复杂修饰键；当前静态/纯规则通过不等于Java实机视觉/行为完全一致。

反馈格式：环境/分辨率/DPR、对应G行、初始组与光标、精确实体输入、结果、是否误转向/误Use、截图或短视频。P2试听/后台人工清单保留在原路径，不因本轮测试关闭。
