## 实际工程

- `app/web/src/ui/inventory-state.ts`：纯临时命令、锁定门禁、九格选择/循环、基础来源复制/取放/拆半/合并/交换、装备条件；独立于DOM/Three/存档，不授物。
- `inventory.ts`：原版creative `tab_items`/`tab_inventory`背景、slot精灵、hotbar/selection、Tooltip九宫格、位图文字和透明语义按钮。屏幕二维，不是网页卡片或三维面板。
- 目录主线采用既有MAINLINE的18个固定索引，未解锁黑色蒙版仍可查看名称；副产物由首次解锁顺序追加。滚轮只滚动下方副产物，主线两行保持固定。装备页把原版背景的普通27格区域重投影为 **同一个无限目录**，没有创建有限普通背包。
- 两页入口仍独立；仅game加载目录与九格，主页故事/正面桌子/宽屏构图不改。普通Items (E)按钮与E开关，Esc关闭；游戏1–9/滚轮选择，GUI数字键对来源复制到指定九格。GUI/设置拥有输入时，先关闭三维输入并取消世界指针手势，关闭后恢复。
- `icon-model.ts`/`icons.ts`：原版item definition选择、模型父继承、纹理引用、display.gui、元素旋转/rescale、草色调、特殊实体几何及组合变换。独立图标适配器不扩大SceneView的方块/世界模型能力。
- 预生成的图标仅为浏览器内存Canvas；原版PNG/JSON仍作为源文件发布，不拿其他物品的图片回退。一次性离屏WebGL图标生成后释放GPU对象/上下文，缓存CPU图像。切石机锯片按原mcmeta的20Hz帧序列预渲染并选择缓存帧；UI动画更新不替换语义按钮。

当前基础来源操作：空光标左/右各复制1；同类左增1、右减1（至原版上限）；中键空光标复制最大组；来源数字键按最大组填对应九格。不同类光标点击来源暂不销毁或替换其内容。普通九格/装备支持基础左右取放。Shift来源、双击收拢、完整拖动、数字悬浮交换等不是本次完整交付，不能把它们的暂未实现说成永久删减。
