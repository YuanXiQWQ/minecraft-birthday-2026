## 实现和边界

- `app/web/src/domain/slots.ts`：独立SlotPolicy，take/place、容量、装备组件、接收谓词；pickup、distribute、quickMove、collect。可供P6菜单复用，但不实现结果槽onTake、合成消费/剩余物或炉加工。输出可设place=false；正式结果领取必须另接D05处理器，不能照搬普通槽。
- `domain/inventory.ts`：目录与有限载体的纯命令。九格、光标、装备、副手、九组可选预设；没有第二套有限普通背包。所有来源、旧载体和预设均先检查当前解锁。默认数量上限/装备条件来自原26.3字段投影，不按名称后缀判断。临时移动守恒；复制和Q删除分别作为显式操作，不撤销永久解锁、不生成地面实体。
- `ui/slot-gesture.ts`、`inventory-input.ts`：在释放时提交拖动，合法槽去重；左拖floor均分，容量不足留下余数；右拖每格一个；中拖填本物品最大组并保留原光标。只有已持有光标组的拖动执行分配。越界、失焦、PointerCancel、捕获丢失、Esc、界面切换/缩放和异常鼠标按键组合取消未提交手势。取消不回滚已经提交的点击。
- `ui/inventory.ts`：复用原版像素GUI/113图标/Tooltip。数量变化保持语义按钮及焦点，避免重建DOM打断输入；动画只切换缓存帧。GUI输入和场景Look完全分离。短右击经原有阈值仲裁后才Use，可把当前原版装备放入/交换到组件指定槽；拖动不装备、不Use。原视角边界、眼位、主页故事和桌面构图不改。
- 支持显式damage/custom_data身份；原版默认damage=0与省略相等，非同组件不合并。不引入工具磨损。任意max_stack_size/equippable等未实现组件覆盖会拒绝，不能通过它绕开数量/装备条件。非默认饰纹/装饰、完整Java着色、损伤条/复杂组件视觉仍不宣称一致；当前目录113种默认图标沿用已审查范围。

## 明确的项目适配

1. **Shift**：目录一次最多复制一个原版最大组，有限九格依次合并后填空；快捷栏装备可移入空的合法装备槽，装备/副手可移回九格。没有打开容器时，普通快捷栏物品没有第二套有限背包可转移，保持原位，不在九格间无意义重排。P6接入站点后提供站点路由。Shift双击只处理匹配的有限来源快照，不扫描无限目录；目录两次点击最多各复制一组，不采用“直到来源耗尽”。
2. **数字/F**：世界数字选择；GUI数字按悬浮真实槽双向权限交换，悬浮目录复制最大组。GUI空白处不改变世界选择。F在世界交换选中九格与副手，在GUI按悬浮真实槽交换，目录F复制最大组到副手。两端均检查原版上限/装备许可。
3. **Q/Ctrl+Q**：清除悬浮真实槽/世界选中组的一个/整组；GUI目录没有可丢弃有限来源。不产生地面实体，解锁不减。点击界面外丢弃光标未增加新规则，仍待退出适配审查，不能把它算完整G17通过。
4. **C/X**：保留九组原版式工具栏能力，C+1–9保存九格，X+1–9加载；只复制稳定临时布局，不含装备/光标，不授予解锁。预设与其他载体一样重新校验原版上限及解锁，重置清除。保存的是当前数量，不把所有引用都强制变成最大组。
5. 编辑焦点/设置拥有输入时不吃游戏键；Ctrl/Alt/Meta组合保留浏览器行为，只有作用域内Ctrl+Q是明确适配。Chromium已实际执行；Firefox的Ctrl+Q/其他引擎、触控板、OS快捷键仍需对应环境核验，不能从Chromium推断。

每次`SaveSession.editInventory(intent,cursor,expectedLayout)`均取得同名Web Lock、重读最新信封、验证generation/生命周期、检查完整载体前置值，再在锁内运行领域命令。不是普通revision比较，也不是UI上传改好的存档。两个页面同时拿同一组只能一次成功，另一次inventory-conflict且更新到最新布局；设置/解锁等不相关命令继续合并。UI串行提交乐观临时投影，失败撤销未提交投影，光标保持最后一次成功结果；不在pagehide上传旧快照。

重置清除九格、装备、副手、预设，保留语言/音量/静音；重置代次同时使旧光标和排队旧操作失效。该进度重置是已明确要求，不代表D07关闭/刷新政策获批。
