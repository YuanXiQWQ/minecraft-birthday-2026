# Minecraft Java Edition 26.3 runtime resources

This directory contains the bounded original resource cohort used by the existing prototype. It is tracked in Git and included in normal development, build and preview output. No local Minecraft installation, private cache, environment variable or manual extraction is required to run the implemented features.

`minecraft/26.3/manifest.json` records source version, provenance, file sizes, SHA-256 values, original sound object identities and the explicitly derived twelve-event sound definition subset. The 95 resource files preserve the used model parents, textures, UV/state inputs, animation metadata, GUI assets, ASCII font subset, item definitions, particle frames and Ogg samples. The complete client and unrelated resources are not included.

The current font adapter intentionally supports the ASCII bitmap provider, not every provider referenced by the original font definitions. The additive `minecraft/26.3/presentation-manifest.json` records 17 exact original files: seven cake models, its blockstate, four cake textures and five oak slab/post/plank models. The P2 manifest stays unchanged. The P3 profile was 114 files including both manifests. The current formal app adds catalogue-manifest.json and 359 exact original resources for 113 default item icons, native catalogue/hotbar/slot/Tooltip GUI dependencies: 474 files including three manifests. The P2 and P3 manifests stay unchanged. Full component variants, Java shader parity and held/entity contexts are outside this GUI slice. Cake slice variants have offline conversion coverage; the browser presentation uses the uncut cake only. The authored table assembles transformed original slab/post models; it is not a native Minecraft table block. Broader game content remains future work.

Development use is approved by the project owner. This statement is not a claim of permission from the rights holder for public redistribution. Public-release terms remain a separate review; there is no mandatory replacement with hand-drawn assets. Any later custom replacement must be explicitly requested and audited per resource category, including audio separately.

The formal Vite plugin in `app/tools/resources.ts` emits only files in these two profiles under its configured base path. The existing P2 plugin continues using its original bounded profile. This README, project documents, test records, JAR files and personal extraction paths are not runtime assets. Ordinary `app/` dev/build/preview requires no extraction step; `app/tools/import-home-assets.ps1` is an optional maintenance importer for the version-checked client.
