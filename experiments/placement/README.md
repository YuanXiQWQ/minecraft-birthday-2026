# P1 补充：A/B 放置隔离实验

只用于验证放置、有限容器、漏斗和持久化的技术复杂度。不是正式游戏、P2 工程或原版一致性验收。实验推荐不构成产品批准。

## 运行与复现

在仓库根目录，使用已有 Node.js（本机实测 v25.2.1；其他版本未验证），无需安装任何依赖：

```powershell
node experiments/placement/server.mjs
```

浏览器打开 `http://127.0.0.1:4177/`。服务器只监听本机，只返回明确白名单中的实验页面和模块；不会提供仓库、文档、测试或原始资产。按 Ctrl+C 停止。端口冲突可在 PowerShell 设置 `$env:PLACEMENT_PORT = '4178'` 后运行。

```powershell
node --test experiments/placement/tests/placement.test.mjs
node experiments/placement/verify.mjs
```

后一命令输出四条 A/B 熔炉/高炉轨迹、可恢复 JSON 快照和四漏斗循环统计；无网络、无文件写入。保存的实际执行结果在 [results/](results/)，完整审查报告见 [放置实验报告](../../docs/p1/placement-experiment.md)。测试日志中的毫秒是测试运行时间，不能推导开发工时。

## 浏览器操作

1. `Load A furnace demo`：固定工作台和炉，输入/燃料各一个。推进 200 tick，领取输出才解锁铁锭。使用 Operation 的 Place/Remove 与替换勾选框测试固定位置生命周期。
2. `Load B furnace demo`：四个五槽漏斗、工作台、炉。上方粗铁、侧面木棍、下方抽取、相邻收集。依次 Step 200、8、1，到 tick 209 后 Inspect `[4,1,0]`：五槽中的第一槽有一个铁锭。
3. `Load B blast-furnace demo`：同一链路换高炉；Step 200 后也能看到输出，精确 tick 109 的轨迹由 CLI/测试复现。两者不是吞吐性能对照。
4. 选择 Facing 后 Rotate，检查 Derived live connections；移动目标或更换方向无需手工维护连接记录。单元标签为 x,y,z，Y 向上；Depth layer 切换 z=0/1。上/下关系与背景图无关。
5. Inspector 左键移动整组，右键拆半/放一；目录按明确调试数量复制，Quick-route 按输入优先路由。**按钮不等同完整 Shift 键或创造目录行为**。
6. Save experiment → 刷新 → Restore experiment，再 Inspect 原实例。保存设备内容、方向、冷却及进度；清光标/事件。独立 localStorage key，不接正式存档。
7. Fresh B 从网格采集自然节点后可覆盖空位，Leave/revisit 不覆盖工作站；移除后下次 revisit 恢复自然来源。`Load tight workspace fixture` 只给两个可建位置，用来验证必要工作站空间保护。

## 模块边界

| 文件 | 职责 |
| --- | --- |
| core/definitions.mjs | 少量样本物品/配方、设备槽数、测试场景、调试解锁 |
| core/containers.mjs | 有限组、容量、槽权限、面访问、快速路由、原子移动 |
| core/placement.mjs | A/B 位置策略、占用、样本能力保护 |
| core/flow.mjs | B 的邻接派生、推送/抽取、冷却及有限调度 |
| core/model.mjs | 共用命令事务、设备生命周期、加工、采集补货、永久解锁 |
| core/persistence.mjs | 实验版本化快照与加载校验 |
| ui.mjs / labels.mjs / index.html / styles.css | 独立诊断界面、英文提示、占位图形 |
| server.mjs / verify.mjs / tests/ | 本机服务、场景证据、自动化反例 |

没有 package.json、构建配置、第三方依赖、正式应用入口或原版素材。未来生产构建必须只接受正式入口和资产白名单，不能递归复制仓库；该生产构建目前不存在，隔离性不等于已验证未来构建。

## 必须保留的简化说明

- 单个合成测试空间，B 为 7×5×2 个逻辑格；不是四场景、最终布局、3D 渲染、玩家移动或世界模拟。A 为一个工作台槽和两个可互换炉槽；工作台只有临时九槽，不执行合成。
- 初始直接授予调试解锁，样本来源/工具等级/燃料/五条配方均手工声明；没有正式数据导出、全配方、组件等价、递归闭包或主线蛋糕可达性证明。
- 遵循 GUI 文档推荐候选：永久解锁 U 不减；目录复制有限临时组；搬运扣源增目标；炉保留输入/燃料引用，按周期续燃、输出受上限约束；领取/成功自动转移才获取产物；光标不持久化。只获准用于本实验。
- 剩余物只测试预置桶的底面抽取权限，不执行蛋糕三桶、燃料剩余物生成或全量标签解释。快捷栏/装备/完整输入矩阵和配方书均未实现。
- 漏斗五种出口、五槽及容器连接存在；没有红石、掉落实体、水流、箱子放置或无限地图。每 tick 先加工、再按稳定实例 ID 调度；每只最多推一/拉一，8 tick 冷却、tick 初源预算避免同 tick 透传。**没有复现原版相邻漏斗 7/8 tick 协调分支或证明原版时序一致**。
- 时间通过显式按钮/命令推进，没有真实帧调度、后台/离线推进、多标签写入协调或正式迁移。防软锁仅证明手工样本的铁/工具/燃料及工作空间；农田/蛋糕桌面是受保护占位，不表示已实现种植或庆典。
- 拆除/替换清实例和其临时内容，U 不变；这是实验候选。只有完整命令完成后才能保存，不保存半次传输；没有承诺正式撤销机制。
